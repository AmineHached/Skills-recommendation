# Skills-recommendation
The Skills Recommendation App analyzes university program data and identifies skill gaps by comparing the skills provided by programs with those demanded in the job market. Using semantic similarity and fuzzy string matching, this app helps align educational programs with industry requirements.

## Features
- Semantic similarity analysis using Sentence Transformers.
- Fuzzy string matching for job titles.
